# Raulnik Royce

Landing de apresentação profissional em HTML5, CSS e JavaScript.

O site está em [portfolio.raulnikroyce.dev](https://portfolio.raulnikroyce.dev/).

## Desenvolvimento

```bash
npx --yes serve .
```

Ou abra `index.html` no navegador.

## Deploy

Netlify publica a raiz (`publish = "."` no `netlify.toml`), sem build. O domínio aponta para esse projeto.
